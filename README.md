# Interview Prep Samples 2026

This repository contains multiple small sample projects for interview practice:

- java-core: Java snippets (LRU cache + tests)
- sql-plsql: Oracle DDL and PL/SQL package examples
- spring-boot-samples: small Spring Boot JPA + stored-proc examples (H2 for local run)
- react-samples: small React sample components
- todo-react: To‑Do React app that persists to localStorage

See each folder for run instructions.
